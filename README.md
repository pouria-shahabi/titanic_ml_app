# 🚢 Titanic Survival Prediction

A complete end-to-end Machine Learning project based on the famous Titanic dataset.
This project focuses on data preprocessing, feature engineering, model training, and deployment as an interactive web application.

## 🔍 Project Overview
The goal of this project is to predict whether a passenger survived the Titanic disaster based on personal and travel-related features.

## 🧠 Machine Learning Pipeline
- Data cleaning & preprocessing
- Feature engineering
- Model training with scikit-learn
- Model persistence using joblib
- Web-based inference using Streamlit

## 🛠 Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Streamlit
- Hugging Face Spaces (Deployment)
